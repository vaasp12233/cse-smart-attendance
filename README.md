# CSE Smart Attendance Management System
A role-based web application built with PHP and MySQL to automate student attendance logging using dynamic QR code generation and verification.

## Tech Stack
- **Backend:** PHP (Session-based Auth, RBAC)
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Containerization:** Docker

## Running Locally via Docker
1. Clone the repository:
   ```bash
   git clone https://github.com/vaasp12233/cse-smart-attendance.git
   cd cse-smart-attendance
   ```
2. Build and run with Docker Compose:
   ```bash
   docker-compose up --build
   ```
3. Open `http://localhost:80` in your browser.
